π-Lingual Edge

3-way offline voice translation on a barebones Raspberry Pi 4. Speak in English, Hindi, or Slovak. Completely local context. No API keys attached.

View on GitHub Explore Architecture
⚡️

Edge AI Optimized

Uses whisper.cpp and qwen2.5:1.5b via Ollama to bring heavy LLM translation pipelines to a $50 ARM computer with just 4GB RAM.

🔒

100% Offline

Transcription, translation, and TTS happen locally. The only network call needed is gTTS for Hindi responses. Your voice stays on your device.

🎙️

Real-time Feedback

A lightweight Flask server provides Server-Sent Events, streaming live terminal updates and audio waveform activity to any browser on your network.
